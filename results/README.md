# Numerical results

`manuscript_tables/` contains nine main and 51 supplementary CSV display tables. Full-precision outputs, predictions, histories, assignments and parameters are in `../reproducibility/`; rounded display tables do not replace those records.

There are 228 completed neural fits: 60 reference, 120 repeated-P5 and 48 P6/P7. Calibration fits are separate. Original RGB images and large trained checkpoint payloads are excluded.
